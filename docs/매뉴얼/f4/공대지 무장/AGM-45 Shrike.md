# AGM-45 Shrike

## 개요

AGM-45 슈라이크는 AIM-7 스패로우 공대공 미사일을 기반으로 제작되었으며 적의 방공이 내뿜는 레이더를 역추적해 파괴하는 대레이더 미사일이다

대레이더 미사일의 초기형인만큼 애로사항이 많은 무장이다 

적 방공에 종류에 따라 키트를 장착해줘야되고, AGM-88C HARM는 적 레이더를 실시간으로 위치를 찾아 파일럿에게 보여주지만 슈라이크는 적 방공의 위치를 향해 기수를 맞추질 않으면 찾지도 못한다 그렇기에 이륙하기전엔 무조건 적 방공의 종류와 위치등을 정확하게
파악하고 진입하지 않으면 SEAD는 커녕 슈라이크를 파일런에 그대로 달고 다시 돌아오거나 혼자서 장거리 비행하고 있는 슈라이크를 볼 수 있게된다

팬텀에 장착 가능한 슈라이크는 A형과 B형이 있으며 A형은 10마일 B형은 25마일정도의 사거리를 가진다

1. 슈라이크가 달려 있는 파일런을 선택해준다 명중률이 좋은편은 아니므로 한번에 다 발사하는게 좋다
2. 마스터 암을 올려준다
3. 딜리버리 모드를 AGM-45 Mode로 설정해준다
4. 웨폰 셀렉트 노브를 ARM로 설정한다
5. HUD 모드를 A/G로 설정해준다
6. 파일럿 우측 무릎쯤에 있는 FD 노브를 가로로 둔다, 해당 노브를 가로로 두게되면 중앙 자세계에 노란색 가로선과 새로선이 생긴다 해당 노란색 선중에서 새로선은 현재 키트로 탐지 가능한 적 방공 레이더 방향쪽으로 기수를 맞출 수 있게 도와준다
7. Missle Reject 스위치를 DF로 둔다
