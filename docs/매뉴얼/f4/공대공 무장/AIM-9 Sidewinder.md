## 사용법

<img width="1110" height="798" alt="image" src="https://github.com/user-attachments/assets/d4b2cf17-d785-4b6d-8054-461db9821d5d" />

사이드 와인더는 각 2번 8번 파일런의 좌우에 장착이 가능하며 최대 4발까지 장착이 가능하다

기본적으로 사이드와인더를 장착 할 경우 2번 8번 파일런에는 무장 장착이 불가하지만 스패셜 웨폰 어답터에 장착되는 공대지 무장은 스페셜 웨폰 어답터를 사용하여 같이 장착 가능하다

<img width="1793" height="1253" alt="1" src="https://github.com/user-attachments/assets/ab3e0c97-f2e5-4a9f-9f29-79940ecc6e52" />

1. 공대공 무장을 열추적으로 바꿔준다 ( 기본 설정 기준 단축키 : L Shift + S )
2. 마스터 암을 올려준다
3. 딜리버리 노브는 OFF or 다이렉트, 웨폰 셀렉트는 RKTS & DISP으로 설정한다
4. HUD 모드를 A/A로 설정한다
